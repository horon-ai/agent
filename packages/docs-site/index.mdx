One Rust binary. Four model wires.

horon agent is a coding agent with a terminal client of its own. It runs a turn,
calls tools and exits — or stays up as a daemon that the client, SDKs, editors and
host programs attach to over a Unix socket.

```sh
curl -fsSL https://raw.githubusercontent.com/horon-ai/agent/main/scripts/install/install.sh | bash
horon provider current --json
horon run "summarize this repo"
```

## At a glance

<CardGroup cols={3}>
  <Card title="Two binaries">
    `horon-agent` runs the agent: `serve`, `run`, `repl`, `api-bridge`, `acp`, `rpc`.
    The terminal client `horon-tui` is separate and built on the SDK.
  </Card>
  <Card title="Append-only sessions">
    History is an event log with content-addressed blobs. Archive, compaction and
    rewind append records and never delete an original.
  </Card>
  <Card title="ACP v1 and v2">
    Editors negotiate either version; `initialize` answers with the highest both
    sides support.
  </Card>
