## Top level

| Path | What it holds |
| --- | --- |
| `src/` | The CLI: `serve`, `run`, `repl`, `api-bridge`, `acp`, and their dispatch |
| `crates/` | The workspace crates: `base`, `app-core`, `agent-runtime`, `session-store`, `harness-api`, `harness-api-server`, `agent-sdk`, `extension-types`, `extension-sdk` (author SDK kept out of `horon-agent`), `tui` (the `horon-tui` binary), plus provider and `platform*` crates |
| `docs/` | Behaviour documentation, compiled into the binary and served by the `documentation` tool |
| `packages/sdk/typescript` | `@horon-ai/agent-sdk` |
| `packages/sdk/python` | `horon-agent-sdk` |
| `packages/npm/horon` | `@horon-ai/horon` launcher |
| `packages/docs-site` | This documentation site (Mintlify) |
| `scripts/` | CI gates, release and install scripts, benchmarks |
| `tests/` | Workspace-level integration tests |

## Checks

GitHub Actions owns workspace-wide builds, `clippy`, `cargo test --workspace`,
and `compare` benchmarks (`AGENTS.md`); run scoped single-crate checks and
non-Cargo gates locally:

| Area | Command |
| --- | --- |
| Single-crate check | `cargo check --locked -p <crate>` |
| Docs corpus test | `cargo test --locked -p horon-agent-app-core --lib horon_agent_docs` |
| Agent graph (no terminal crates) | `python3 scripts/ci/check_headless_graph.py` |
| Dependency boundaries | `python3 scripts/ci/check_dependency_boundaries.py` |
| Docs links & pairs | `python3 scripts/ci/check_docs_links.py` / `check_docs_pairs.py` |
| Docs site sync | `python3 scripts/ci/sync_docs_site.py --check` |

Performance measurement runs only in GitHub Actions; the comparison suite builds
the baseline and the candidate on one runner, so a before/after difference is not
a compiler difference.
