상태는 #557 설계 제안이다. 프로바이더 역할과 설정할 수 있는 기존 임베딩 백엔드가 있다. 이 제안으로 기존 기능이 모델을 자동으로 내려받는 일은 생기지 않는다. [프로바이더 모델](/ko/reference/provider/model)

## 설계 결정

| 선택지 | 결과 |
| --- | --- |
| 실행 환경과 모델 가중치를 함께 배포 | 모든 사용자의 설치 크기와 시작 작업이 늘어난다. |
| 타입이 정해진 작은 보조 기능을 외부 백엔드에서 선택 실행 | 하나의 호출 계약을 재사용하고 실행 환경과 모델 파일은 기본 설치 밖에 둔다. 이 방식을 선택한다. |
| 기능마다 모델 로더 추가 | 모델 검증, 장치 선택과 캐시 규칙이 중복된다. |

## 동작 계약

`suggest_title` 동작 하나로 시작한다. 버전이 정해진 요청은 호출 기능에서 민감 정보를 가린 UTF-8 텍스트를 최대 4 KiB까지 받고 80자 이내의 제목 하나와 사용한 백엔드 정보를 돌려준다. 첫 구현은 모의 백엔드로 진행할 수 있다. 메모리 벡터와 예측 기능은 각각 데이터 계약과 개인정보 처리, 대체 경로를 정한 뒤 이 인터페이스를 사용할 수 있다. 보조 기능에는 프로바이더 자격 증명과 전체 세션 상태를 주지 않는다.

백엔드 선언에는 모델 이름, 바뀌지 않는 리비전, 라이선스 참조, 파일 크기와 SHA-256 해시를 고정한다. 사용자가 설치를 요청하면 승인된 매니페스트를 확인하고 전체 바이트를 제한하며 임시 디렉터리에 파일을 받아 해시를 모두 확인한다. 완전한 리비전만 한 번에 활성화하며 설치 실패 시 이전 리비전을 계속 쓸 수 있다. 캐시를 켜지 않으면 사용자가 검증된 로컬 모델 폴더를 직접 지정한다. 캐시는 사용자별로 켜고 모델 리비전과 해시로 구분한다. 시작, 첫 사용, 재시도와 대체 경로는 다운로드를 시작하지 않는다. 실제 모델을 승인하기 전에 라이선스, 의존성 크기와 초기화 비용을 검토한다. 개발 중 시험 데이터가 읽을 수 있다는 사실만으로 가중치를 배포하지 않는다.

사용자는 `auto`, `cpu` 또는 백엔드가 알려 준 가속기와 지원 정밀도 중에서 고른다. `auto`는 사용할 수 있는 조합을 고른다. 지원하지 않는 장치나 정밀도를 지정하면 `unsupported_device`나 `unsupported_precision`을 반환하고 결정적인 제목 자르기처럼 기존 로컬 대체 경로를 사용한다. 이유와 경로를 호출 기능에 전달한다. 캐시가 없거나 출력 형식이 잘못됐거나 제한 시간이 지나면 기존 기능 결과를 유지한다. 백엔드마다 한 번에 한 건, 기본 2초로 제한하고 암묵적인 네트워크나 원격 추론 호출을 하지 않는다. 시간 초과, 취소 또는 완료 시 자식 프로세스 자원을 해제한다.

## 구현 경계

1. `crates/config-types/src/lib.rs`에 기본으로 꺼진 설정을 추가하고 지정한 장치, 정밀도와 캐시를 검증한다. 일반 시작은 보조 기능을 초기화하거나 파일을 읽고 쓰지 않는다.
2. `crates/base/src/`에 타입이 정해진 어댑터와 모의 백엔드를 쓰는 제목 기능 하나를 둔다. 추론 의존성 없이 취소와 대체 경로, 모델 메타데이터를 확인한다.
3. 검증 설치를 별도로 구현하기 전에 독립 라이선스를 가진 모델과 엔진 하나의 파일 크기, 메모리와 지연을 GitHub Actions에서 검토한다. TUI는 기존의 타입이 정해진 API를 호출한다.

## 검증

`cargo test --locked -p horon-agent-config-types --lib`를 실행한다. GitHub Actions는 격리한 홈과 모의 자식 프로세스를 쓰고 네트워크를 차단한다. 기본 설정으로 시작해 감시한 디렉터리에 다운로드, 자식 프로세스 실행과 캐시 쓰기가 모두 0건인지 확인한다. 시험 기능을 켜고 모의 CPU에서 `Plan release`를 보내면 `Release plan`을 기대한다. 지원하지 않는 시험용 가속기를 요청하면 `unsupported_device`와 고정 대체 제목 `Plan release`가 나오며 다운로드는 0건이다. 해시가 다른 모델은 활성화되지 않고 시간 초과나 취소 이후에는 자식 프로세스가 남지 않아야 한다.
